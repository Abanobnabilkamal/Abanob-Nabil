A modern, responsive, high-performance personal portfolio website built for **Abanob Nabil Kamal**, Machine Learning & AI Engineer and Computer Science & Artificial Intelligence student at Beni Suef University.

## 🌟 Portfolio Highlights

- **Dark High-Tech Aesthetics**: Inspired by modern AI interfaces with dark navy backdrops (`#050814`), isometric/fine grid lines, vibrant cyan glow accents (`#38bdf8`), and angled light-ray spotlight illumination.
- **Featured Project Showcase**: Complete spotlight on the **House Price Prediction System** (NTI Graduation Project) featuring:
  - Architecture breakdown, algorithms (XGBoost Classifier, Ridge Regression, XGBoost Regressor), feature engineering, and metrics.
  - **Live In-Browser ML Simulator Widget**: Allows visitors to test real-time house valuation estimates with living area, bedrooms, bathrooms, and model architecture comparison.
- **Official Credentials & Verification**:
  - High-resolution interactive certificate lightbox modal for the **NTI Machine Learning Summer Training Course** (120 Hours, 94% Distinction score).
  - Direct download link to the official certificate PDF (`assets/certificate_nti.pdf`).
  - Recognition of the **DEPI (Digital Egypt Pioneers Initiative)** under MCIT.
- **Interactive Capabilities**:
  - Filterable Skills Matrix (Machine Learning & AI, Programming & Core, Data Science & Viz, Tools & DevOps).
  - One-click copy-to-clipboard for Email and Phone with toast feedback.
  - Interactive Contact Form with automated pre-filled email client triggering.
  - Fully responsive across desktop, tablet, and mobile with accessible drawer navigation.
  - Zero build steps or heavy dependencies: 100% portable pure HTML5, CSS3, and modern JavaScript.

## 🚀 How to Run Locally

### Option 1: Direct File Open
Simply double-click `index.html` or open it in any modern browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### Option 2: Local Python Server (Recommended)
Open a terminal in the `d:/Portfolio` directory and run:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.

## 🌐 How to Deploy to GitHub Pages (Free)

1. Create a new GitHub repository named `portfolio` or `abanob-portfolio` under your GitHub account (`https://github.com/Abanobnabilkamal`).
2. Push this folder to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of modern ML & AI portfolio"
   git branch -M main
   git remote add origin https://github.com/Abanobnabilkamal/portfolio.git
   git push -u origin main
   ```
3. In GitHub repo settings, go to **Pages** -> under **Branch**, choose `main` and root `/`, then click **Save**.
4. Your portfolio will be live at `https://abanobnabilkamal.github.io/portfolio/`!
